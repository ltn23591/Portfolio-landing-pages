# Lê Trung Nghĩa — Software Engineer Portfolio

Trang Portfolio cá nhân được xây dựng với **React 19**, **Vite**, **Tailwind CSS v4**, **Three.js** và hiệu ứng giao diện từ **React Bits** (`https://reactbits.dev/`), sử dụng bộ font chữ **Orbitron** & **Space Grotesk**.

## Cấu trúc 8 phần cốt lõi

1. **Introduce (`Hero.jsx`)**: Tiêu đề, ảnh chân dung cá nhân, giới thiệu ngắn gọn và tải CV (PDF).
2. **Education (`About.jsx`)**: Học vấn chính quy và chứng chỉ chuyên môn.
3. **Personal Skill (`About.jsx`)**: Điểm mạnh cốt lõi của bản thân và ma trận kỹ năng công nghệ (Backend, Frontend, Database, DevOps).
4. **Work Experience (`Experience.jsx`)**: Kinh nghiệm làm việc thực tế kèm các thành tựu định lượng súc tích.
5. **Projects (`Projects.jsx`)**: Tổng hợp các dự án công nghệ nổi bật có phân loại danh mục.
6. **Project Detail (`Projects.jsx`)**: Modal chi tiết từng dự án tập trung vào các chỉ số kết quả đạt được (Key Metrics) và điểm nhấn kiến trúc.
7. **Best Project (`Projects.jsx`)**: Khu vực Featured làm nổi bật dự án tâm đắc nhất cùng các kết quả đột phá.
8. **Contact (`Contact.jsx`)**: Thông tin liên hệ công việc (Số điện thoại/Zalo, Email, GitHub, LinkedIn, Telegram) và biểu mẫu gửi tin nhắn trực tiếp.

## Chạy dự án

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển (Development)
npm run dev

# Kiểm tra mã nguồn (ESLint)
npm run lint

# Đóng gói bản dựng Production
npm run build
```
